# Sonic TV Interface Release Notes

SonicDE's big-screen interface for TVs, designed to be used from the sofa with a remote or game controller.

## Unreleased

- Now presents itself with SonicDE names and identity throughout the desktop.
- The TV session is now called "SonicDE TV" on the login screen, in every language SonicDE is translated into. If you used it before, choose it once more after upgrading.
- The on-screen keyboard is back: it opens when a text field gets focus, including from a remote or game controller.

## 6.8.0 (2026-10-20)

- Behind the scenes: developer tooling support, code style clean-ups, updated to build against SonicDE 6.8.0 and a version number update.

## 6.7.5 (2026-09-12)

- The TV interface now runs on SonicDE's X11 desktop in place of Wayland.
- Fewer legacy compatibility packages are needed: the old Plasma and Qt 5 support libraries are no longer required.
- Behind the scenes: version number update.
